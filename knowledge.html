    LINUX USER ACCOUNTS
    There are three different types of accounts: root, standard user, and service. The root user account plays two roles on a Linux system. The first role is that of the local administrator. A user logged on as root can do administrative tasks such as password resets, system configuration changes, user account management, etc. The second role played by the root user account is to provide a security context for some applications and commands entered by a user logged on as root. The root user account in Linux is significantly more powerful than the local administrator account on a Windows® system. #CYBERTOPICS
